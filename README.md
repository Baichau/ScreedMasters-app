# Screed Master

Сайт мастера по устройству стяжки и шлифовке полов в Гомеле и Гомельской области.
Одностраничный сайт-визитка Евгения Окунева с информацией об услугах, примерами
работ, отзывами и формой обратной связи.

**Website:** [baichau.github.io/ScreedMasters-app](https://baichau.github.io/ScreedMasters-app/)

## Возможности

- Адаптивная вёрстка для телефонов, планшетов и компьютеров.
- Мобильное меню и плавная навигация по разделам.
- Аккордеон с ответами на частые вопросы.
- Слайдер отзывов клиентов.
- Галерея работ «До/После».
- Форма обратной связи на FormSubmit.
- Яндекс.Метрика для аналитики посещений.
- Локальные изображения включены в репозиторий.

## Запуск локально

Склонируйте репозиторий и откройте `index.html` в браузере. Внешний веб-сервер
для просмотра не требуется.

Для приёма сообщений настройте форму в FormSubmit и укажите выданный сервисом
адрес формы в атрибуте `action` в `index.html`. Не размещайте личный адрес
получателя в опубликованном исходном коде.

## Технологии

HTML5, CSS3, JavaScript (ES6), Font Awesome, Google Fonts, FormSubmit и
Яндекс.Метрика.

### Portfolio case study

**The challenge:** A local floor-screed and polishing contractor needed a clear
way to explain his services, build trust with prospective customers and show
real project outcomes on both desktop and mobile.

**What I built:** A responsive one-page website with a mobile menu, FAQ
accordion, customer reviews slider, before-and-after project gallery, contact
form and analytics.

**The result:** The contractor's services, reviews, work examples and contact
options are brought together in one mobile-friendly page, giving prospective
customers a straightforward path from browsing to making an enquiry.
